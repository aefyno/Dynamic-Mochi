
## Устройство кода
- `src/DynamicMochi/IslandWindow.xaml(.cs)` — капсула: раскрытие при наведении, вкладки Главная / Музыка / Настройки, строка песни под капсулой
- `Services/MediaService.cs` — SMTC: что играет, обложка, позиция, кнопки, перемотка
- `Services/LyricsService.cs` — поиск текста на lrclib (логика из Mac-версии, см. ниже)
- `Services/Themes.cs` — темы; новая тема = одна строчка
- `Services/Settings.cs` — `%APPDATA%\DynamicMochi\settings.json`
- `Services/AutoStart.cs` — автозапуск через `HKCU\...\Run`
- `Services/Native.cs` — окно без фокуса и без Alt+Tab
- `.github/workflows/build.yml` — сборка на windows-latest при каждом пуше

## Текст песен — правила (проверены на Mac)
1. Искать только когда плеер уже знает длину трека
2. Название совпадает целиком (почти-совпадение — только для длинных), исполнитель — хотя бы частично
3. Длина ±8 с; speed up / slowed — тайминги оригинала растягиваются
4. Из подходящих — самый полный; нет вступления — берём из обычного текста той же записи
5. Нет ответа / нет сети — повтор через 15 с, до 4 раз, таймаут 10 с
6. Позиция досчитывается между опросами; бэк-вокал в скобках — мельче и курсивом; вступление и проигрыши — три точки
