# Dynamic Mochi: задание v1.5 (идеи)

Этен → Бену. Делать **сразу после v1.4**, в этой же сессии (тестер проверит всё утром). Сначала полностью закончи v1.4, выпусти её отдельным коммитом и релизом, и только потом начинай v1.5 — чтобы если v1.5 что-то сломает, у тестера осталась рабочая v1.4. Общие правила дизайна и тем — как раньше. Каждая фича включается/выключается тумблером в окне настроек (раздел указан). Коммиты как раньше.

Порядок: 1 → 3 → 8 → 2 → 5 → 6 → 7 → 4.

---

## 1. Громкость и яркость в острове вместо окна Windows
- При нажатии клавиш громкости / mute / яркости — системная плашка Windows не показывается, вместо неё капсула плавно расширяется до ~360 × 58: иконка (динамик с волнами по уровню / солнце) 18 px, полоска уровня во всю ширину (высота 6, цвет `Accent`), число справа «65». Держится 1.5 с после последнего нажатия, затем обратно.
- Если играет музыка — уровень показывается поверх свёрнутого вида музыки, без потери обложки.
- Технически: перехват через `RegisterHotKey` нельзя (ломает клавиши) — использовать низкоуровневый хук клавиатуры только для отслеживания + чтение уровня через Core Audio (`IAudioEndpointVolume`, событие `OnNotify`) и яркости через WMI (`WmiMonitorBrightnessEvent`). Скрытие системной плашки — через известный способ с окном `NativeHWNDHost`/`DirectUIHWND`; если на конкретной сборке Windows не получается — оставить системную, но наш показ всё равно работает.
- Настройки → Общее: «Громкость и яркость в острове».

## 2. Наушники и зарядка
- Подключились Bluetooth-наушники/колонка: капсула на 4 с показывает иконку устройства, название («AirPods Pro») и заряд в процентах с иконкой батареи, если Windows его отдаёт (`Windows.Devices.Enumeration` + свойство батареи BLE/`DEVPKEY_Bluetooth_Battery`). Отключились — короткое «Отключено».
- Ноутбук: подключили зарядку — молния + процент и «до полной ≈ 1 ч 20 мин»; заряд ≤ 20% — однократное предупреждение цветом `#FF9F0A`, ≤ 10% — `#FF453A`.
- Настройки → Общее: «Устройства и батарея».

## 3. Индикатор микрофона и камеры
- Когда какое-то приложение использует микрофон — на капсуле справа маленькая оранжевая точка 6 px `#FF9F0A`; камеру — зелёная `#30D158` (как на iPhone). Обе — если и то, и другое.
- При наведении на точку — подсказка, какое приложение («Discord использует микрофон»).
- Технически: реестр `HKCU\Software\Microsoft\Windows\CurrentVersion\CapabilityAccessManager\ConsentStore\microphone` / `webcam` — у записи активного приложения `LastUsedTimeStop = 0`. Опрос раз в 1 с, без нагрузки.
- Настройки → Общее: «Индикатор микрофона и камеры» (по умолчанию вкл).

## 4. Полка для файлов
- Перетаскиваешь файл(ы) на капсулу — она подсвечивается контуром `Accent` и раскрывается в режим «Полка»: файлы лежат иконками 48 px с названием. Можно положить до 10.
- Перетаскиваешь файл с полки в любую папку/окно — он туда копируется (обычный drag-and-drop Windows). Правый клик — «Открыть», «Показать в папке», «Убрать с полки».
- Пока на полке что-то есть — в свёрнутом виде маленький значок полки с числом.
- Полка хранит только ссылки на файлы, не копии. Очищается при перезапуске (опция «Помнить полку»).
- Настройки → Общее: «Полка для файлов».

## 5. Не беспокоить
- В раскрытом острове на Главной — кнопка-луна; в трее — пункт меню; горячая клавиша `Win+Alt+D`.
- Включено: уведомления (Telegram/Discord/скриншоты) не всплывают, на капсуле маленькая луна. Напоминания календаря и таймер — показываются (опция).
- Таймер «Не беспокоить на 1 час / до утра / пока не выключу».
- Автоматически в полноэкранных приложениях — опция.
- Настройки → Уведомления (новый раздел, туда же переехать настройки уведомлений из v1.4).

## 6. Помодоро
- В режиме «Таймер» вкладки Календарь — кнопка «Помодоро»: 25 мин работы → 5 мин отдыха, каждый 4-й отдых — 15 мин. Длительности настраиваются.
- В свёрнутом виде кольцо прогресса: работа — цвет `Accent`, отдых — зелёный `#30D158`; рядом «Работа 18:42» / «Отдых 03:10» и номер круга «2/4».
- Смена фазы — мягкий звук и короткое расширение капсулы с подписью.

## 7. Загрузки
- Отслеживать папку «Загрузки» (и папки, добавленные в настройках): появился растущий файл (`.crdownload`, `.part`, `.tmp` или размер растёт) — в капсуле иконка загрузки, имя файла, прогресс (если известен итоговый размер) и скорость «12.4 МБ/с». Готово — галочка + «Открыть».
- Несколько загрузок — показывать «3 загрузки», общий прогресс.
- Настройки → Общее: «Загрузки в острове».

## 8. Автообновление
- Раз в 6 часов и при запуске проверять последний релиз в `aefyno/Dynamic-Mochi` (GitHub API `releases/latest` — для этого начать выпускать нормальные релизы с номером версии `v1.5.0` и т.д., а не только `build-*`).
- Есть новая версия — один раз ненавязчиво в капсуле «Доступна 1.5.1» + кнопка «Обновить». Плюс в окне настроек → О программе: текущая версия, «Проверить обновления», список изменений из описания релиза.
- Обновление: скачать exe во временную папку, проверить размер/хеш (опубликовать SHA-256 в описании релиза), заменить себя через маленький bat/helper после выхода, перезапуститься. Настройки сохраняются.
- Настройки → О программе: «Проверять обновления автоматически».
