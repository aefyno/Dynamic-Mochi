# Dynamic Mochi: дизайн-спека v1.1 (переделка фазы 1)

Это задание на полный проход по дизайну и багам фазы 1. Делай строго по пунктам, каждую цифру — как написано. Если что-то технически невозможно в WPF — сделай ближайший вариант и напиши об этом в CONTRIBUTING.md.

Перед началом смёржи `fix/cleanup` в `phase-1` (комменты на английском, CONTRIBUTING.md вместо HANDOFF.md, CI выкладывает сборку в Releases). Коммиты — на английском.

Вкладок по-прежнему три: Главная, Музыка, Настройки. Новых функций не добавлять — только дизайн, анимации и баги.

## 0. Общие принципы

- Ощущение: дорогой системный элемент, как Dynamic Island у iPhone. Плотно, крупно, без пустых дыр, всё живое и плавное.
- Ничего не прыгает: любые изменения размера, цвета, текста — через анимацию.
- Одна сетка отступов: **4 / 8 / 12 / 16 / 20 px**. Других значений не использовать.
- Скругления: капсула = половина высоты в свёрнутом виде, **28 px** в раскрытом; карточки **16**; обложки **8** (маленькие) / **12–14** (большие); кнопки-плашки **10**.
- Иконки — только Segoe Fluent Icons, без эмодзи.
- Шрифты:
  - цифры часов и крупные заголовки — `Segoe UI Variable Display`, SemiBold;
  - остальной текст — `Segoe UI Variable Text`;
  - все цифры (часы, таймкоды) — моноширинные: `Typography.NumeralAlignment="Tabular"`, чтобы не дрожали.
- Чёткость на 125–150%: `UseLayoutRounding="True"`, `SnapsToDevicePixels="True"`, `TextOptions.TextFormattingMode="Display"` для мелкого текста.
- Длинные названия: не обрезать многоточием сразу, а **бегущая строка** (marquee): пауза 1.5 с → едет со скоростью 30 px/с → пауза 1.5 с → плавный возврат. Края — fade-маска 12 px слева и справа.

### Токены темы (что должна задавать каждая тема)

| Токен | Назначение |
|---|---|
| `Bg` | фон капсулы (может быть градиентом) |
| `Surface` | фон карточек и плашек внутри |
| `SurfaceHover` | наведение на плашку |
| `Fg` | основной текст |
| `Sub` | вторичный текст (≈60% от Fg) |
| `Faint` | третичный: таймкоды, подписи (≈40%) |
| `Accent` | активная вкладка, прогресс, эквалайзер, включённый тумблер |
| `AccentFg` | иконка/текст поверх Accent |
| `Border` | обводка капсулы (может быть прозрачной) |
| `Glow` | цвет внешнего свечения (может быть прозрачным) |
| `ToggleOff` | выключенный тумблер — **всегда нейтральный серый** |

### Анимации (единые для всего проекта)

| Что | Длительность | Кривая |
|---|---|---|
| Раскрытие капсулы | 380 мс | пружина: `BackEase EaseOut, Amplitude 0.25` (лёгкий перелёт ~3%) |
| Сворачивание | 260 мс | `CubicEase EaseInOut` |
| Появление контента после раскрытия | 180 мс, задержка 120 мс | fade 0→1 + сдвиг вверх 6 px → 0 |
| Элементы внутри вкладки | каскадом по 30 мс | так же |
| Смена вкладки | 200 мс | старая: fade-out + сдвиг 8 px в сторону ухода, новая: fade-in + сдвиг с противоположной стороны; высота капсулы плавно подстраивается |
| Наведение на кнопку | 120 мс | фон `SurfaceHover`, масштаб 1.0 → 1.06 |
| Нажатие | 90 мс | масштаб → 0.94, отпустил → 1.0 |
| Смена темы | 250 мс | плавный переход всех цветов (анимировать `Color`, а не подменять кисть) |
| Смена трека | 220 мс | обложка crossfade + лёгкий «squish» капсулы (ширина ×1.03 и обратно) |

Тайминги наведения: раскрыть через **150 мс** после наведения (чтобы не открывалась от случайного пролёта мыши), свернуть через **400 мс** после ухода. Если мышь вернулась — отменить сворачивание.

## 1. Свёрнутая капсула

**Размер:** `320 × 44` (сейчас 230×38 — мало). Отступ от верха экрана **8 px**. По центру основного монитора, с учётом DPI.

**Тень:** мягкая `DropShadow` (blur 24, opacity 0.45, сдвиг вниз 6). В теме с `Glow` — дополнительное свечение цвета `Glow`.

### 1.1 Играет музыка
Слева направо, вертикально по центру, внутренние отступы 8 слева / 14 справа:

1. **Обложка** 30×30, скругление 8. Нет обложки — плашка `Surface` с иконкой ноты `Sub`.
2. Отступ 10.
3. **Название трека** 13 px SemiBold `Fg`, marquee. Под ним исполнитель не нужен.
4. Гибкое пространство.
5. **Эквалайзер:** 4 полоски, ширина 3, зазор 2, скругление 1.5, цвет `Accent`. Высота каждой случайно меняется в пределах 4–16 px, каждые ~120 мс, с плавной интерполяцией, у полосок разные фазы. На паузе — плавно оседают до 3 px и замирают (сейчас вместо этого статичные `••••` — баг).
6. Отступ 10, тонкий разделитель 1×16 `Faint`, отступ 10.
7. **Часы** `HH:mm`, 13 px SemiBold `Fg`, tabular. Видны **всегда**.

### 1.2 Пауза
Как 1.1, но эквалайзер осел, название — `Sub` вместо `Fg`, обложка затемнена на 30%.

### 1.3 Ничего не играет
Капсула плавно ужимается до **200 × 44**. По центру: часы 14 px SemiBold, точка-разделитель `Faint`, дата «Пт, 30 окт» 12 px `Sub`.

### 1.4 Ховер на свёрнутой
За 150 мс до раскрытия — капсула чуть подрастает (масштаб 1.02) и обводка становится чуть ярче. Это «предвкушение» раскрытия.

- **Баг сейчас:** строка не появляется (тест: «Рваные джинсы — Элджей», настройка включена). Проверить весь путь. В `log.txt` писать: запрос (название, исполнитель, длина), сколько результатов пришло, какой выбран и почему / «текст не найден» / ошибку сети. Без этого лога баг не отладить.

## 8. Микро-детали, которые часто забывают

- Курсор «рука» над всем кликабельным.
- Тултипы на иконках вкладок и кнопках плеера (задержка 600 мс), стилизованные под тему, а не системные серые.
- Окно не забирает фокус ни при каком клике (уже сделано — не сломать).
- Если трек сменился, пока капсула раскрыта, — карточки обновляются с crossfade, а не мгновенно.
- При закрытии приложения капсула сворачивается в точку (scale → 0, 200 мс), а не исчезает рывком.
- При запуске — появляется из точки (scale 0 → 1 с пружиной, 450 мс).
- Таймкоды не «прыгают» шириной (tabular).
- Нет обложки → градиентная заглушка из цвета Accent + иконка ноты, не пустой квадрат.
- Все тексты на русском, с заглавной буквы, без точек в конце коротких подписей.
- Проверить на 100%, 125%, 150% масштабе: ничего не размыто, не обрезано, капсула ровно по центру.
